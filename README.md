📊 Customer Behaviour Analysis – End-to-End Data Analytics Project

Turning raw data into business insights using Python, MySQL, Power BI, and AI-assisted reporting.
📌 Overview

This project walks through a complete data analytics workflow: from loading and cleaning raw data to answering business questions with SQL, visualizing results in Power BI, and presenting findings in a report and slide deck.

Business Goal: "Identify which product categories drive the most revenue, customer reviews, how many loyal customers, revenue by customer category "

🔄 Project Steps

1. Data Loading (Python) Imported the dataset into a Pandas DataFrame and reviewed its structure, data types, and size.

2. Exploratory Data Analysis (EDA) Examined distributions, correlations, outliers, and trends using summary statistics and visualizations.

3. Data Cleaning Handled missing values, removed duplicates, fixed data types, and standardized formats. The cleaned file was saved for downstream use.

4. SQL Analysis (MySQL) Loaded the cleaned data into MySQL and wrote queries to answer key business questions using joins, aggregations, CTEs, and window functions.

5. Dashboard (Power BI) Built an interactive dashboard with KPIs, filters, and charts to explore performance at a glance.

6. Report Documented the methodology, findings, and recommendations in a written report.

7. Presentation (Gamma + Claude) Used Claude to draft the storyline and key talking points, then Gamma to generate a polished slide deck.
